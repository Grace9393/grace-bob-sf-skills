# Pre-Session Client Checklist

Share this with the client contact at least 48 hours before the first discovery session.
Ask them to prepare or locate the following before the call.

---

## Access & Permissions

- [ ] Salesforce System Administrator credentials for the production org
- [ ] Access to Setup → Company Information (edition, storage, user counts)
- [ ] Access to Setup → Health Check (export the current score and findings)
- [ ] Access to Setup → Installed Packages list
- [ ] Access to Salesforce contract / order form (licence counts, add-ons, renewal date)

## Technical Artefacts

- [ ] Apex test coverage report (Developer Console → Tests → Run All, or from CI pipeline)
- [ ] List of all sandbox orgs with their type and purpose
- [ ] Integration inventory — list of all systems connected to Salesforce (can be informal)
- [ ] Deployment methodology documentation (change sets, SFDX pipeline, DevOps tool)
- [ ] Any existing architecture or data flow diagrams

## Governance & Documentation

- [ ] Most recent security audit or penetration test findings (if available)
- [ ] Data retention policy document
- [ ] Disaster recovery / business continuity plan for Salesforce (if exists)
- [ ] Compliance certifications relevant to the org (ISO 27001, Cyber Essentials, etc.)
- [ ] List of regulatory frameworks applicable to the organisation (GDPR, HIPAA, SOX, etc.)

## Business Context

- [ ] Organisational chart for teams using Salesforce
- [ ] List of business-critical processes that depend on Salesforce
- [ ] Any known issues, pain points, or recent incidents
- [ ] Pending projects or initiatives that will affect the org in the next 12 months
- [ ] Headcount growth forecast for Salesforce-using teams (12–24 months)

---

## What Happens in the Session

The IBM consultant will work through up to 12 health domains. Each domain takes
approximately 15–30 minutes depending on complexity. Sessions can be split across
multiple calls — the consultant will track progress and resume from where you left off.

The output is a prioritised Org Health Report covering risks, remediation
recommendations, and innovation opportunities.
